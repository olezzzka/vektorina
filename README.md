# CS2 Skin Quiz — конвейер коротких видео

Генерит вертикальные ролики-викторины «какой скин дороже» для TikTok / Reels / Shorts.
Одна команда: собирает свежие цены → подбирает пары → качает картинки → рендерит mp4 + текст поста.

```bash
npm install
cp .env.example .env       # вписать ключ и voice_id ElevenLabs (для озвучки)
npm run build              # 1 ролик с озвучкой и субтитрами
node scripts/build.mjs --count 5     # 5 роликов подряд
node scripts/build.mjs --no-voice    # без озвучки (нет ключа / кончилась квота)
```

Результат: `out/videos/<id>.mp4`, текст поста `out/captions/<id>.txt`.

Локальные правки настроек — в `config.local.json` (не в гите, мёржится поверх `config.json`).

---

## Что откуда берётся

| Слой | Источник | Стоимость |
|---|---|---|
| Каталог скинов + картинки | [ByMykel/CSGO-API](https://github.com/ByMykel/CSGO-API) | бесплатно |
| Цены (по умолчанию) | снапшот Steam Market из [counter-strike-price-tracker](https://github.com/ByMykel/counter-strike-price-tracker) | бесплатно, обновляется ~раз в сутки |
| Цены (альтернатива) | публичный API Skinport | бесплатно, кэш 5 минут |
| Точечная сверка | Steam Market напрямую | бесплатно, ~20 запросов/мин |

Сменить провайдера: `priceProvider` в `config.json` или `node scripts/fetch-data.mjs --provider skinport`.

Перед публикацией можно уточнить цены только тех 10 позиций, что попали в ролик:

```bash
node scripts/verify-prices.mjs out/quizzes/<id>.json --drop
```

`--drop` выкинет раунд, если после уточнения разрыв меньше 15% — чтобы в комментариях не спорили.

## Как подбираются пары

Это главная логика, в `scripts/make-quiz.mjs`:

- **Сложность растёт по ходу ролика.** Раунд 1 — разрыв в 5–8 раз, раунд 5 — 1.4–2 раза. Держит досмотр.
- **Ловушки** (`trapChance`, по умолчанию 45%): более редкий или более пафосный скин стоит дешевле. Это то, на чём люди попадаются и идут в комменты спорить.
- **Квота на ножи** (`knifeChance`, 25%): иначе алгоритм скатывается в «нож против ножа», а это скучно и не про массовую аудиторию.
- **Уклон в узнаваемое** — AK, AWP, M4, Glock, Deagle весят больше случайного MP7.
- **Анти-повтор**: `data/used.json` помнит все использованные пары и сколько раз показывался каждый предмет (`maxUsesPerItem`).

Крутилки — в `config.json`.

## Шаблон видео

Remotion (React → mp4), 1080×1920, 30 fps, ~33 секунды: интро 2с + 5 раундов по 5.6с + аутро 3с.

Правишь визуал в `src/components/`, смотришь вживую с горячей перезагрузкой:

```bash
npm run studio
```

Превью всегда показывает последнюю сгенерированную викторину (`src/sample-quiz.json`).

Тайминги раундов — `config.json` → `timing` (в кадрах, 30 = секунда). Хочешь быстрее — уменьшай `countdown`.

## Озвучка и субтитры

Реплики генерируются вместе с викториной (`scripts/narration.mjs`) и лежат в JSON
с точной привязкой к кадрам. Дальше `scripts/voice.mjs`:

- каждая реплика — отдельный запрос к ElevenLabs, клип ложится ровно на свой кадр,
  рассинхрон невозможен по построению;
- кэш по хэшу текста в `data/tts-cache/` — повторяющиеся фразы («Раунд 3!»)
  озвучиваются один раз за всю жизнь проекта, экономит квоту;
- если фраза длиннее окна — ускорение до 1.15x, потом укороченный вариант фразы;
- дорожка собирается ffmpeg-ом в `public/voice/<id>.wav` и вшивается в рендер.

Ключи — в `.env` (`ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID`). Без ключей ролик
собирается без голоса. Громкости слоёв — `config.json` → `audio` (голос — `voice`).

Субтитры (`src/components/Captions.tsx`) рисуются из тех же реплик — текст точный
по построению, распознавание речи не нужно. Выключить: `captions.enabled: false`.

## Реалистичный рабочий цикл

1. Раз в неделю ночью — крон на 7 роликов:
   ```
   0 3 * * 1  cd /path/to/cs2quiz && node scripts/build.mjs --count 7 >> logs/build.log 2>&1
   ```
2. Утром просматриваешь `out/videos/`, выкидываешь неудачные (2 минуты).
3. Публикуешь вручную из приложения, **добавляя трендовый звук**. Нативное аудио даёт кратно больше охвата, чем вшитое в файл — поэтому финальный шаг сознательно не автоматизирован.

Про API публикации: TikTok Content Posting API требует отдельного аудита приложения для публичных постов, без него всё уходит в черновики или `SELF_ONLY`. Instagram Reels через Graph API — Business-аккаунт плюс ревью приложения. Черновики автоматизировать можно, полный автопостинг — только после аудита.

## Форматы викторин

Три готовых формата, выбираются флагом `--format` (или `format` в config):

```bash
npm run build                           # duel — «что дороже» (по умолчанию)
node scripts/build.mjs --format price   # «угадай цену»: один скин, варианты A/B/C
node scripts/build.mjs --format odd     # «что лишнее»: три скина, один из другой лиги
node scripts/build.mjs --format random  # случайный формат на каждый ролик
```

- **duel** — два скина, что дороже. Ловушки, нарастающая сложность.
- **price** — один скин и три цены; разброс вариантов сужается к концу ролика.
- **odd** — три скина, один из другой ценовой лиги (дороже или дешевле остальных
  в 3–9 раз, к финалу разрыв меньше). На реврил показываются все цены.

Реплики, субтитры и сценарий озвучки подстраиваются под формат автоматически.
Сверка цен `verify-prices.mjs` работает только для duel.

Идеи на потом: «этот скин стоит как…» (сравнение с бытовыми предметами),
«тогда и сейчас» (нужна история цен — платные API).

## Структура

```
config.json              все настройки (config.local.json — личные правки, вне гита)
.env                     ключи ElevenLabs (вне гита, шаблон — .env.example)
scripts/fetch-data.mjs   каталог + цены → data/catalog.json
scripts/make-quiz.mjs    подбор пар + реплики → out/quizzes/<id>.json + текст поста
scripts/narration.mjs    реплики озвучки по кадрам (вызывается из make-quiz)
scripts/download-images.mjs  картинки → public/images/
scripts/voice.mjs        TTS ElevenLabs → public/voice/<id>.wav
scripts/verify-prices.mjs    точечная сверка со Steam
scripts/render.mjs       рендер mp4
scripts/build.mjs        всё вместе (--no-voice — пропустить озвучку)
src/                     шаблон видео (Remotion)
```

## Требования

Node 18+. Remotion при первом рендере скачает свой Chromium (~150 МБ) — это нормально.
Если Chromium уже есть, можно указать свой: `REMOTION_BROWSER_EXECUTABLE=/path/to/chrome npm run render`.

## Оговорки

- Цены — снапшот Steam. Ставь дату на экран (она уже есть в тексте поста), иначе в комментариях будет «это неправда».
- Каталог и цены — неофициальные сообщественные источники, у них бывают простои. Кэш в `data/` позволяет собрать ролик даже когда источник лежит.
- Не привязывай подписи к скин-гемблингу и раздачам — модерация TikTok такое душит.
